# Resume Matcher

This project is a tool for matching resumes to job descriptions.

## Features

*   Parses resumes in PDF and DOCX formats.
*   Generates embeddings for resumes and job descriptions.
*   Calculates similarity scores between resumes and job descriptions.
*   Provides a Streamlit UI for uploading resumes and viewing matching results.
*   Offers an API for programmatic access to the matching functionality.
